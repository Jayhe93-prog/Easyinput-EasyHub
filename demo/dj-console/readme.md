# EasyInput · DJ 控制键盘（网页版 3D）

单文件 HTML 实现的网页版 DJ 控制键盘，复刻真实 VB Coding 键盘的 3D 数模外观，纯 CSS 3D + 原生 JS，无需依赖，浏览器直接打开即用。

## 文件说明
| 文件 | 作用 |
| --- | --- |
| `EasyInput-DJ Console.html` | 唯一主文件，全部代码（结构 / 样式 / 逻辑） |
| `进展.md` | 功能开发记录，后续跑前先读 |
| `错误经验.md` | 踩坑与规避方法，后续跑前先读 |

## 功能总览
- **8 键布局**：S1 播放/暂停、S2 Hot Cue、S3 打点、S4 返回、S5 闪停、S6 加鼓、S7 加速、S8 减速。
- **Hot Cue / Cue-Pause**：每 Deck 4 个打点键，打点后自动暂停可选。
- **音量旋钮**：3D 拟物滚轮，带刻度环、进度弧、指示点；可独立上色。
- **展示**：实时显示当前速度 ×N 与音量 %。
- **外观定制**：键帽 PBT 配色 / 外壳样式 / 滚轮配色 / 逐键配色 / 一键整套皮肤 / 视角切换。
- **工具**：机械键盘按键音（可静音）、拍照模式（Esc 隐藏全部 UI）、配置导出/导入（JSON 字符串）。

## 常用入口
- 左栏底部「工具」：按键音开关、拍照模式、导出/载入配置。
- 左栏「3D 键帽 / 外壳 / 滚轮」面板：外观定制。

## 运行
直接用浏览器打开 HTML 文件即可。开发提示：改完刷新，控制台应无 JS 报错。
